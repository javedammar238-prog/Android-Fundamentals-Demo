# Android Fundamentals Demo (Java)

A consolidated Android project written in **Java** demonstrating:
1. **Activity Lifecycle Callbacks** (Logging state transitions)
2. **Multiple View OnClick Listeners** (Anonymous & Interface implementations)
3. **Bidirectional Intent Data Transfer** (Forward and backward data passing using `ActivityResultLauncher` and `setResult`)

## Files Included:
- `AndroidManifest.xml`
- `MainActivity.java`
- `SecondActivity.java`
- `activity_main.xml`
- `activity_second.xml`
